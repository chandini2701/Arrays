01 / BASICS

What is an Array?

Understand the foundation of arrays in Java.

Definition

An array in Java is a collection of elements of the same data type stored under a single variable name. Each element is accessed using its index position.

Indexing

Array indexing starts from 0. The first element is at index 0, the second at index 1, and the last element is at length - 1.

Fixed Size

Once an array is created, its length cannot be changed. The size must be specified when creating the array.

Java - Array Declaration JAVA 
int[] numbers = new int[5];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
numbers[3] = 40;
numbers[4] = 50;

System.out.println(numbers[0]); // 10

05 / JAVA PROGRAMS

Practical Examples

Learn important array programs with Java code.

Example 1: Print Array Elements

Use a for loop to print all array values.

class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30, 40, 50};

        for(int i = 0; i < a.length; i++) {
            System.out.println(a[i]);
        }
    }
}
Output: 10 20 30 40 50

Example 2: Find Sum

Add all elements present in an array.

class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30, 40};
        int sum = 0;

        for(int i = 0; i < a.length; i++) {
            sum = sum + a[i];
        }

        System.out.println(sum);
    }
}
Output: 100

Example 3: Find Largest Element

Find the maximum value in an array.

class Main {
    public static void main(String[] args) {
        int[] a = {12, 45, 23, 67, 34};
        int max = a[0];

        for(int i = 1; i < a.length; i++) {
            if(a[i] > max) {
                max = a[i];
            }
        }

        System.out.println(max);
    }
}
Output: 67

Example 4: Reverse an Array

Print the elements in reverse order.

class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30, 40, 50};

        for(int i = a.length - 1; i >= 0; i--) {
            System.out.print(a[i] + " ");
        }
    }
}
Output: 50 40 30 20 10

Example 5: Two-Dimensional Array

Print matrix elements using nested loops.

class Main {
    public static void main(String[] args) {
        int[][] a = {
            {10, 20},
            {30, 40}
        };

        for(int i = 0; i < a.length; i++) {
            for(int j = 0; j < a[i].length; j++) {
                System.out.print(a[i][j] + " ");
            }
            System.out.println();
        }
    }
}
Output:
10 20
30 40

Example 6: Search an Element

Find whether a particular value exists.

class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30, 40};
        int search = 30;
        boolean found = false;

        for(int i = 0; i < a.length; i++) {
            if(a[i] == search) {
                found = true;
                break;
            }
        }

        System.out.println(found);
    }
}
Output: true

07 / SUMMARY

Advantages & Limitations

Advantages

  • Stores multiple values under one name.
  • Provides direct access using indexes.
  • Easy to traverse using loops.
  • Useful for storing similar types of data.
  • Supports one-dimensional and multidimensional structures.

Limitations

  • Fixed size after creation.
  • Stores elements of one declared component type.
  • Insertion and deletion may require shifting elements.
  • Invalid indexes cause ArrayIndexOutOfBoundsException.
  • Resizing requires creating another array or using a dynamic collection.
